# Segmentação semântica de imagens de satélite

## Visão geral

Projeto de visão computacional voltado à identificação de áreas de mata em imagens de satélite, criado no contexto do trabalho publicado na SVR 2023 sobre análise imersiva para planejamento de operações militares.

## Objetivo

Automatizar a separação de regiões de vegetação para apoiar a preparação de terrenos utilizados no ambiente de Realidade Virtual.

## Abordagem

- Aplicação das técnicas de *watershed* e *region growing*.
- Segmentação semântica de imagens de satélite para destacar regiões de mata.
- Geração de dados para apoiar a recriação e a análise de terrenos no ambiente imersivo.
