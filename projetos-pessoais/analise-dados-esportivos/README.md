# Análise visual de dados esportivos

## Visão geral

Ferramenta para explorar dados de partidas de futebol de forma visual, conectando eventos de jogo, posicionamento de atletas e relações táticas no campo.

## Objetivo

Tornar conjuntos de dados esportivos mais fáceis de interpretar, apoiando a identificação de padrões e a comunicação de análises para diferentes públicos.

## Principais pontos

- Visualização de dados de partidas em representações espaciais do campo.
- Exploração de relações entre atletas, eventos e movimentações.
- Base para estudos de análise esportiva e experiências imersivas.
