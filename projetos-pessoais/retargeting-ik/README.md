# Retargeting e IK para personagens 3D

## Visão geral

Projeto pessoal de aplicação de **retargeting** e **cinemática inversa (IK)** para transferir dados de captura de movimento a personagens 3D.

## Objetivo

Preservar as poses e os movimentos capturados ao adaptá-los para personagens com diferentes proporções e estruturas de esqueleto.

## Abordagem

- Leitura dos dados de captura de movimento.
- Mapeamento entre o esqueleto capturado e o personagem 3D.
- Uso de IK para ajustar os membros e manter o contato corporal esperado.
- Avaliação visual do movimento transferido.
